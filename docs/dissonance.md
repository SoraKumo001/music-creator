# 不協和音の解消（後処理レイヤー）

生成した曲に残る「短2度・短9度（半音関係）」の衝突を、**全声部を横断して検出し、
優先度の低い声部だけを動かして解消する**仕組み。

## 1. なぜ必要か

各声部は生成時に局所的な衝突回避を行っている。

- `texture.ts`: ハモリはコードトーン・旋律と半音にならない音を選ぶ
- `accompaniment.ts`: コード伴奏は旋律と重なる位置を避ける
- `voicing.ts`: 1和音内の密集（半音）を避ける

しかし声部をまたぐと衝突が残る。実測では生成曲1曲あたり **約9件/100音** の衝突があり、
主な発生源は次の組み合わせだった。

| 衝突ペア | 例 |
|---|---|
| Chords × Seq16 | 16分シーケンスとコードの声部が半音でぶつかる |
| Pad × Seq16 | 持続パッドと16分の経過音 |
| Chords × Melody | 旋律の経過音とコードトーン |
| Bass × Melody | ベースのルートと旋律の半音上の音（b9） |

## 2. 方針

- **旋律（優先度0）は絶対に動かさない**
- 優先度の低い声部だけを、次の順で直す
  1. **repitch**: その拍のコードトーン／スケール音へ移す（近い順、ユニゾンより3度・5度を優先）
  2. **trim**: 相手の音が始まる手前で切る
  3. **drop**: それでも駄目なら落とす
- 優先度: Melody 0 > Bass 1 > Chords 2 > Counter 3 > Harmony 4 > Pad 5 > Seq16 6 > Arp 7
- 決定的（乱数なし）。最大6パス・最大600修正で打ち切り

## 3. 使い方

パイプラインには組み込み済みで、`compose()` の最後（`assemble` の後、`normalizeScore` の前）に
自動で適用される。結果は `stats` に出る。

```ts
const result = await compose(cfg, prompt, 32);
result.stats.dissonanceFixes       // 修正した数
result.stats.dissonancesRemaining  // 残った衝突数（通常0）
```

単体で使う場合:

```ts
import { findDissonances, reduceDissonances } from "./src/theory/dissonance";

const hits = findDissonances(tracks);           // 検出
const { tracks: fixed, fixes, remaining } = reduceDissonances(tracks, {
  chordTonesAt: (beat) => chordAt(events, beat).tones,
  scaleTonesAt: (beat) => SCALES[scale].map(i => (i + root) % 12),
});
```

評価:

```bash
npm run eval:dissonance                 # フィクスチャで測定（ネットワーク不要）
npm run eval:dissonance -- --live --bars=32   # 実際に生成して測定
```

## 4. 実測

### フィクスチャ12曲（単旋律を付けて組み立て）

| 指標 | 値 |
|---|---|
| 後処理前 | 312 件（8.40 件/100音） |
| 後処理後 | **0 件** |
| 修正の内訳 | repitch が大半、trim 0、drop 2（解析不能なキーの曲のみ） |

### 実生成3曲（32小節・rich）

| 曲 | 後処理前 | 後処理後 | 修正数 |
|---|---|---|---|
| 疾走感のあるゲームステージBGM | 194 (7.74/100音) | **0** | 153 |
| 静かなローファイ | 148 (8.83/100音) | **0** | 110 |
| 明るいアニメ風ポップ | 264 (10.48/100音) | **0** | 209 |

修正の大半は**コードトーンへの移調**（音の数は減らない）。音が消える drop は全体の数%に留まる。

## 5. 判定ルールの詳細

- 対象: 異なるトラック間の、半音関係（ピッチクラス距離 1）の音
- 重なり: 0.2拍以上、かつ短い方の音の 35% 以上
  （境界のわずかな食い込みや、短い経過音の一瞬の交差は無視）
- 除外: ドラム（チャンネル9）、同一トラック内、ユニゾン・オクターブ・5度・トライトーン
  （トライトーンは7th和音やドミナントで意図的に使われるため対象外）

## 6. 既知の制限

- 半音関係のみを対象にしている。長7度（maj7）とルートの衝突や、低音域の密集など、
  より広い「濁り」は対象外。
- 修正は和音の再解釈を行わないため、稀に「本来の響きと違う和音」に聴こえることがある。
- 旋律の音域・リズムは変更しない代わりに、旋律そのものが原因の衝突は伴奏側を動かす。
  そのため伴奏が単純化される場合がある（drop が発生したケース）。
